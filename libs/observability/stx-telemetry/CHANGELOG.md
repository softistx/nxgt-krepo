# stx-telemetry

The release line for `io.github.softistx:stx-telemetry`, `io.github.softistx:stx-telemetry-ktor`, `io.github.softistx:stx-telemetry-mongo`, `io.github.softistx:stx-telemetry-otlp`, `io.github.softistx:stx-telemetry-slf4j` and `io.github.softistx:stx-telemetry-spring` — they share one version, and ship together.

Up to **0.2.1** every library in this repository shared one version and one changelog; that history
is in [`CHANGELOG.md`](../../../CHANGELOG.md) at the repository root. From here each family moves on
its own, and this file is where it is written.
